# Working in this repository

Instructions for AI coding agents (Claude Code, DSH, Cursor, Codex, anything that reads
`AGENTS.md`).

## If someone asks whether an image is real, fake, AI-generated or edited

Do **not** answer from intuition and do **not** run pixel heuristics first.

Load and follow:

```
skills/image-forensic-triage/SKILL.md
```

The short version, in case the skill is unavailable:

1. Run `image-provenance FILE --mode c2pa`. A manifest is decisive — report it and stop.
2. No manifest → run `skills/image-forensic-triage/scripts/triage.py FILE` for the ledger.
3. Pixel heuristics (`--mode pixels`) are **leads only**. Never quote them as proof, and
   never let them produce an "authentic" verdict.
4. State which evidence grade (A/B/C/D) the file can support. Most forwarded images are C.

## Repository conventions

- Python 3.10+, no runtime dependency beyond the stdlib for tier 1.
- Tier 2 (pixel heuristics) must stay optional: `pip install -e '.[pixel]'`.
- Never make tier 1 depend on tier 2, or vice versa.
- Keep the two-tier contract visible in output text: tier 1 authoritative, tier 2 labelled
  as a guess.

## Before committing

```bash
python -m unittest discover -s tests -v
```

CI runs the same on Python 3.10/3.11/3.12 plus a CLI smoke test.

## Do not commit

- Original photos or documents belonging to real people (ID numbers, seals, address
  watermarks). Test fixtures must be synthetic or generated by a model, and must not carry
  a real person's data.
